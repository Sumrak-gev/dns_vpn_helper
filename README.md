# DNS & VPN Helper 🚀

Компактная утилита для Windows для быстрого переключения между режимами работы сети:
- 🌐 **Обычный интернет (DHCP)** — сброс настроек DNS на автоматическое получение от роутера/провайдера.
- ⚡ **DNS Режим** — установка надежных DNS (Comss.one, AdGuard, Cloudflare, Google и др.) для обхода блокировок и ускорения интернета в один клик.
- 🛡️ **VPN Режим (Happ)** — быстрое переключение на Happ VPN с автоматическим сбросом сторонних DNS для предотвращения конфликтов маршрутизации.
- 🔄 **Авто-получение DNS с Comss.one** — больше не нужно вручную заходить на сайт, копировать IP и вставлять в параметры сетевого адаптера.

---

## 📸 Возможности

1. **3 режима в 1 клик**:
   - `Обычный интернет` (DHCP)
   - `DNS Режим` (с выбором профиля)
   - `VPN Режим` (сброс DNS + запуск Happ)
2. **Автоопределение сетевого адаптера**:
   - Автоматически находит активный интерфейс (Wi-Fi или Ethernet) со шлюзом по умолчанию по индексу сетевого маршрута, исключая ошибки кодировки или русских названий адаптеров.
3. **Парсер актуальных адресов**:
   - Кнопка **«🔄 С сайта Comss»** парсит страницу `https://comss.one/dns`, извлекает свежие серверы и автоматически обновляет сохраненный профиль.
4. **Менеджер профилей**:
   - Встроенные пресеты: Comss.one DNS, AdGuard, Cloudflare (1.1.1.1), Google Public DNS, Quad9, Яндекс DNS.
   - Возможность добавлять свои собственные DNS и удалять ненужные.
5. **Современный UI в стиле Windows 11**:
   - Тёмная тема на базе CustomTkinter.
   - Индикация текущего активного адаптера, состояния DNS и статуса работы Happ VPN.
6. **UAC Helper**:
   - Для изменения настроек сети Windows требует права администратора. Приложение запрашивает UAC один раз при старте, позволяя далее переключать режимы без задержек.

## 🛠️ Установка и запуск

### Вариант 1: Запуск через Python
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Sumrak-gev/dns_vpn_helper.git
   cd dns_vpn_helper
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   run.bat
   # или напрямую через Python:
   py src/main.py
   ```

### Вариант 2: Сборка автономного `.exe` файла
Запустите скрипт сборки:
```bash
build.bat
```
После завершения скомпилированная программа будет находиться в папке `dist/DNS_VPN_Helper.exe`. Она не требует установленного Python и может запускаться автономно.

```

├── src/
│   ├── core/

│   │   ├── parser.py            # Парсер актуальных IP с сайта comss.one/dns
│   │   └── profiles_manager.py  # Хранение, добавление и удаление DNS-профилей
│   ├── ui/
│   │   └── app_window.py        # Графический интерфейс на CustomTkinter
│   └── main.py                  # Точка входа в программу
├── config/
│   └── profiles.json            # Предустановленные профили DNS

├── run.bat                      # Быстрый запуск
├── requirements.txt             # Зависимости проекта
└── README.md                    # Документация
```

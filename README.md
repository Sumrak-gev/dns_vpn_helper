# DNS & VPN Helper (with Zapret DPI Bypass) 🚀

Компактная утилита для Windows для быстрого переключения между режимами работы сети:
- 🌐 **Обычный интернет (DHCP)** — сброс настроек DNS на автоматическое получение от роутера/провайдера.
- ⚡ **DNS Режим** — установка любых DNS-адресов (ручной ввод / пресеты: Comss.one, AdGuard, Cloudflare, Google и др.) для обхода блокировок и ускорения интернета в один клик.
- 🛡️ **Обход блокировок DPI (Zapret / winws)** — ускорение YouTube, разблокировка голосовых каналов Discord и сайтов без VPN.
- 🛡️ **VPN Режим (Happ)** — быстрое переключение на Happ VPN с автоматическим сбросом сторонних DNS и остановкой Zapret для предотвращения конфликтов маршрутизации.
- 🔄 **Авто-получение DNS с Comss.one** — больше не нужно вручную заходить на сайт, копировать IP и вставлять в параметры сетевого адаптера.

## 📸 Модули и возможности (4 вкладки с нижним меню)

1. 🌐 **Вкладка «DNS & Сеть»**:
   - Мгновенный сброс параметров DNS адаптера на автоматические от роутера (DHCP).
   - Поля для прямого ввода любого своего IPv4 адреса (основной + резервный) с кнопкой применения.
   - Каталог готовых DNS профилей (Comss.one, AdGuard, Cloudflare, Google, Quad9, Яндекс).
   - Кнопка **«🏓 Проверить пинг»**: измерение реальной задержки (UDP DNS query port 53) до каждого сервера прямо в списке.
   - Кнопка **«🔄 С сайта Comss»**: автопарсинг свежих DNS с `comss.one/dns`.
   - Сохранение и удаление пользовательских профилей.

2. 🛡️ **Вкладка «Zapret (DPI)»**:
   - Фоновый запуск и остановка `winws.exe` без раздражающих окон консоли.
   - Выбор готовых стратегий обхода: General (YouTube + Discord + Сайты), YouTube TLS Split, Discord Voice (UDP Fix), пользовательские параметры.
   - Поле для прямого редактирования аргументов запуска `winws.exe`.
   - **Привязка файлов**: отслеживание наличия `winws.exe`, `WinDivert.dll`, `WinDivert64.sys`, автообнаружение хостлистов (`.txt`) и пейлоадов (`.bin`) в папке.
   - Быстрый переход в папку с файлами через проводник Windows.
   - Окно операционных логов `winws` в реальном времени.

3. 🚀 **Вкладка «Happ VPN»**:
   - Мониторинг процесса `Happ.exe` (статус, PID, использование памяти).
   - Мониторинг и кнопка быстрого перезапуска службы `HappService`.
   - Кнопка «Включить VPN Режим» — сбрасывает DNS на DHCP, останавливает Zapret (во избежание конфликтов) и запускает/разворачивает Happ.
   - Быстрый доступ к «Сетевым подключениям Windows» (`ncpa.cpl`).

4. ⚙️ **Вкладка «Инфо & Тест»**:
   - Определение внешнего публичного IP-адреса и провайдера.
   - **Тест доступности сервисов**: проверка задержки (ping ms) до YouTube, Discord, Telegram, GitHub и Google.
   - Очистка системного кэша DNS (`ipconfig /flushdns`).
   - Индикация статуса прав администратора (UAC).

## 🛠️ Установка и запуск

### Вариант 1: Запуск через Python
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Sumrak-gev/dns_vpn_helper.git
   cd dns_vpn_helper
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   run.bat
   # или напрямую через Python:
   py src/main.py
   ```

### Вариант 2: Сборка автономного `.exe` файла
Запустите скрипт сборки:
```bash
build.bat
```
После завершения скомпилированная программа будет находиться в папке `dist/DNS_VPN_Helper.exe`. Она не требует установленного Python и может запускаться автономно.

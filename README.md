# DNS & VPN Helper (with Zapret DPI Bypass) 🚀

Компактная утилита для Windows для быстрого переключения между режимами работы сети:
- 🌐 **Обычный интернет (DHCP)** — сброс настроек DNS на автоматическое получение от роутера/провайдера.
- ⚡ **DNS Режим** — установка любых DNS-адресов (ручной ввод / пресеты: Comss.one, AdGuard, Cloudflare, Google и др.) для обхода блокировок и ускорения интернета в один клик.
- 🛡️ **Обход блокировок DPI (Zapret / winws)** — ускорение YouTube, разблокировка голосовых каналов Discord и сайтов без VPN.
- 🛡️ **VPN Режим (Happ)** — быстрое переключение на Happ VPN с автоматическим сбросом сторонних DNS и остановкой Zapret для предотвращения конфликтов маршрутизации.
- 🔄 **Авто-получение DNS с Comss.one** — больше не нужно вручную заходить на сайт, копировать IP и вставлять в параметры сетевого адаптера.

## 📸 Возможности

1. **4 режима работы сети**:
   - `Обычный интернет` (DHCP)
   - `DNS Режим` (с выбором профиля или вводом своих IP)
   - `Zapret DPI Bypass` (модуль winws для YouTube и Discord)
   - `VPN Режим` (сброс DNS + остановка Zapret + запуск Happ)
2. **Ввод и сохранение своих вариантов DNS-адресов**:
   - Поля ввода основного и резервного DNS прямо в главном окне.
   - Можно вставить любой скопированный IP вручную и применить в 1 клик.
   - Кнопка **«💾 Сохранить в профили»** для добавления своих адресов в избранное.
3. **Модуль Zapret (DPI Bypass)**:
   - Включение и остановка `winws.exe` в скрытом фоновом режиме (без всплывающего окна консоли).
   - Готовые стратегии: General (YouTube + Discord + Сайты), YouTube TLS Split, Discord Voice (UDP Fix), пользовательские параметры.
   - Возможность указать папку с существующим Zapret через проводник или поместить в `tools/zapret/`.
4. **Автоопределение сетевого адаптера**:
   - Автоматически находит активный интерфейс (Wi-Fi или Ethernet) со шлюзом по умолчанию по индексу сетевого маршрута, исключая ошибки кодировки или русских названий адаптеров.
5. **Парсер актуальных адресов**:
   - Кнопка **«🔄 С сайта Comss»** парсит страницу `https://comss.one/dns`, извлекает свежие серверы, подставляет в поля ввода и автоматически обновляет сохраненный профиль.
6. **Современный UI в стиле Windows 11**:
   - Тёмная тема на базе CustomTkinter со скроллируемой областью.
   - Индикация текущего активного адаптера, состояния DNS, статуса работы Happ VPN и Zapret.
7. **UAC Helper**:
   - Для изменения настроек сети Windows требует права администратора. Приложение запрашивает UAC один раз при старте, позволяя далее переключать режимы без задержек.

## 🛠️ Установка и запуск

### Вариант 1: Запуск через Python
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Sumrak-gev/dns_vpn_helper.git
   cd dns_vpn_helper
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   run.bat
   # или напрямую через Python:
   py src/main.py
   ```

### Вариант 2: Сборка автономного `.exe` файла
Запустите скрипт сборки:
```bash
build.bat
```
После завершения скомпилированная программа будет находиться в папке `dist/DNS_VPN_Helper.exe`. Она не требует установленного Python и может запускаться автономно.

│   └── main.py                  # Точка входа в программу

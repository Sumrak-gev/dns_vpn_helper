# DNS & VPN Helper 🚀

Удобная компактная утилита для Windows для быстрого переключения между режимами работы сети:
- 🌐 **Прямой интернет (DHCP)** — сброс DNS на авто-получение от роутера/провайдера.
- ⚡ **DNS-профили (Comss, AdGuard, Cloudflare и др.)** — установка надежных DNS для обхода блокировок и ускорения интернета в один клик.
- 🛡️ **VPN (Happ)** — быстрое переключение на Happ VPN с автоматическим сбросом сторонних DNS для предотвращения конфликтов маршрутизации.
- 🔄 **Авто-получение DNS с Comss.one** — больше не нужно вручную заходить на сайт, копировать IP и вставлять в настройки сетевого адаптера.

---

## Возможности
- **3 режима в один клик**: «Обычный интернет», «DNS», «VPN».
- **Автоопределение адаптера**: работает с любым активным сетевым подключением (Wi-Fi или Ethernet).
- **Парсер Comss.one**: автоматическое извлечение актуальных адресов обходного DNS прямо с сайта.
- **Менеджер профилей**: сохранение пользовательских DNS-серверов в удобном формате.
- **Современный UI**: тёмная тема в стиле Windows 11 на базе CustomTkinter.
- **UAC Helper**: корректный запуск с правами администратора для применения сетевых настроек без ошибок.

---

## Установка и запуск

### Требования
- Windows 10 / 11
- Python 3.10+

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск
```bash
py src/main.py
```
*(Приложение запросит права администратора для изменения настроек DNS сетевых адаптеров).*
